# Fuel project

## description
this project is to analyze realtime fuel prices in the UK and understand the trends and factors affecting them. We will be using data from the government website to perform our analysis.

### data taken from goverment website
[Fuel Prices CSV](https://www.fuel-finder.service.gov.uk/internal/v1.0.2/csv/get-latest-fuel-prices-csv)

required libraries:
- flask
- flask-cors
- csv
- requests
- datetime
- threading
